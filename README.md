# YBT

The Your Business Today desktop app for the office Mac mini. It signs in to YBT, talks to the local model in LM Studio, and (as its tasks land) lets James manage YBT by talking to the local model, shows the board of buildable work with the point ranges each model takes, and builds the local model's tasks on a branch for the review model to take to a merged pull request.

`PROJECT.md` has the stack, how the app reaches YBT and LM Studio, and the commands.
